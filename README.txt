First Python API
=============

Descrição
---------
API simples desenvolvida para processo seletivo de uma vaga na CI&T, especificamente para o cliente Rede Globo.
Por ser minha primeira API, ainda está em desenvolvimento e não está em produção

A API doi desenvolvida em Python usando FastAPI. 

Tecnologias Utilizadas
----------------------
- Python 3.10+
- FastAPI
- Uvicorn
- SQLAlchemy
- PostgreSQL
